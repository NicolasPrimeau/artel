How

It knows because everything passes through it.

Every agent writes to the same pad, and the right note surfaces on its own: the gotcha about this file just before you touch it, where you left off on Friday, the lesson another agent already paid for.

It runs on hooks, not instructions, so nothing hinges on an agent remembering. While you are away, an archivist tends the pile, and the pad gets sharper the more it holds.

  you · Claude Code · opencode · Codex · AutoGen · a raw httpx script
        │   hooks push notes in  ┄  sessions captured out
        ▼
   REST / MCP ──► Artel ──► SQLite (WAL) + embeddings
                    ├── notes ── semantic recall · confidence decay · graph
                    ├── captures ──► archivist ──► merged, decayed, promoted
                    ├── decisions ── append-only, never merged
                    └── ledger ── cost per session · per decision · toil
        │
   mesh (CRDT + mDNS) ◄──► your other machines

Inside

Everything in the box.

One container. Every piece has its own page in the docs.

The plugin

The half that speaks up. Injects the right note at session start, on each prompt, and before you edit a file.

Capture

Sessions become notes on their own, spooled in ~10 ms so writing never slows an agent down.

Archivist

The part that learns: merges duplicates, resolves contradictions, decays what stopped being true, promotes what held.

Decisions

Append-only record of what you chose and why. Never merged, never decayed, and what the ledger prices.

Compile mode

Notes about code pinned to the code, so they re-derive instead of rotting.

Blueprints

A procedure compiled into a self-expanding task DAG, with contracts the server checks before a run advances.

Mesh & feeds

Several machines converging as CRDTs, plus RSS/Atom subscriptions from the outside world.

Dashboard

Browse, search and watch the fleet from a browser, alongside the ledger.

Adaptive decay

A control loop tunes how fast confidence fades, measured against notes you actually reach for.

Any agent that speaks HTTP or MCP can join, through 47 MCP tools or the plain REST API.

Run it

Your fleet's memory stays on your machine.

One container, one port, running in a minute.

curl -O https://raw.githubusercontent.com/NicolasPrimeau/artel/master/docker-compose.yml
curl -O https://raw.githubusercontent.com/NicolasPrimeau/artel/master/.env.example
cp .env.example .env
docker compose up -d

Then point an agent at it with curl -fsSL http://<host>:8000/onboard | sh.
