Your agent fleet's notepad, one that learns.

Claude Code on a laptop, Codex on a workstation, a script on a cron: each starts from zero, and none of them knows what the others found out. Artel is the one place they all write to. What one agent learns, the others are handed when it matters, and every note keeps who wrote it and when.

the problem

Without a shared place, the person running the fleet carries the notes.

Every agent is the same model with a different context. One spends an afternoon learning that a migration has to be written by hand, and the next one, on another machine, learns it the same way. Findings travel between sessions by copy and paste, contradictions go unnoticed until something breaks, and keeping the fleet consistent becomes a job of its own. That is manageable with one agent and a real cost at ten.

how it works

Agents never call it. It sits under them and mostly says nothing.

Hooks do the writing and the reading. Each session is captured into notes as it happens, and a note comes back only when it is close to what the agent is doing: one line, once. Most prompts get nothing, which is the point. Over a session of twenty prompts and sixty tool calls the plugin adds about 2,000 tokens.

what it learns

The notepad gets sharper as it fills.

An archivist works through the notes in the background. It merges duplicates, settles notes that contradict each other, lets confidence fade on what stopped being true, and promotes what keeps holding up into reference docs. How fast confidence fades is tuned by a control loop, measured against the notes agents actually reach for.

also in
the container

The same notes, put to more work.

Procedures
A written skill compiled into steps. The server checks each one against the repository, and the agent is handed the next step when the last one is really done.
Decisions
An append-only record of what was chosen and why, never merged or decayed.
Compile mode
Notes about code are pinned to the code they describe, so they are rechecked when it changes instead of going stale.
Mesh and feeds
Several machines converge on one notepad with no central server, and RSS or Atom feeds bring outside news in.
Dashboard
Browse, search and watch the fleet from a browser.

Claude Code gets all of this through a plugin. Anything else that speaks HTTP or MCP can read and write the same notes through the REST API.

run it

Your fleet's notes stay on your machine.

One container, one port, running in a minute.

curl -O https://raw.githubusercontent.com/NicolasPrimeau/artel/master/docker-compose.yml
curl -O https://raw.githubusercontent.com/NicolasPrimeau/artel/master/.env.example
cp .env.example .env
docker compose up -d

Then point an agent at it with curl -fsSL http://<host>:8000/onboard | sh.
